# Gold set

All persons, companies and job postings in this folder are invented for skillpose. Any likeness to real persons or
companies is not intended. The texts were written for this project; none is copied from a real posting.
Universities and certificates (for example Johannes Kepler University Linz, Masaryk University, ISTQB, PL-300) are
real and appear only as typical examples of education.

The folder `translations` holds the translation of each posting into the other language, which the demo shows (see
the README there).
